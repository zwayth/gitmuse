# Changelog

All notable changes to GitMuse will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-07

### Added
- Initial release of GitMuse
- AI-powered commit message generation
- Support for OpenAI GPT models
- Support for Anthropic Claude models
- Support for local models via Ollama
- Interactive mode for choosing commit messages
- Automatic diff analysis and type detection
- Conventional Commits format support
- Emoji support for commit messages
- Configuration management with .gitmuserc
- Scope detection from file paths
- Breaking change detection
- Commit statistics command
- Comprehensive test suite
- CI/CD with GitHub Actions
- Documentation and examples

### Features
- Multiple AI provider support
- Privacy-focused local model option
- Customizable commit message styles
- Team configuration sharing
- Rich terminal output with colors
- Smart code change categorization
